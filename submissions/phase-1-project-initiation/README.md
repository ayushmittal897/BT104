# Phase I — Project Initiation

## Sentinel: Hybrid Network Intrusion Detection System

Sentinel investigates suspicious network-flow data through transparent rules plus a supervised classifier. The scope is offline CICIDS-compatible CSV analysis, a local dashboard, and bounded metadata-only live capture.

## Objectives

1. Classify approved `BENIGN` and `PortScan` flow data.
2. Combine explainable rule evidence with machine-learning output.
3. Present results through a local analyst dashboard.
4. Protect privacy by retaining no packet payloads.

## Limitation

This is an educational decision-support prototype, not a production-wide IDS or a claim of universal attack detection.

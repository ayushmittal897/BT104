# Mid-Term Evaluation

## Prototype

The prototype includes an offline CSV workflow, a local Random Forest inference API, a dashboard, and a bounded local connection-capture proof of concept.

## Demonstration

1. Start the local API and dashboard.
2. Upload a small approved CSV and show the returned prediction summary.
3. Review the result in the dashboard.
4. Start a 60-second metadata-only capture and show connections labelled **Not evaluated**.

Live capture is not classified until an extractor produces the exact model feature schema.

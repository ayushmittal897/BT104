# Capstone Submission Map

| Checkpoint | Folder | Contents |
| --- | --- | --- |
| Phase I — Project Initiation | `phase-1-project-initiation` | problem, scope, novelty, feasibility |
| Phase II — Planning and Design | `phase-2-planning-design` | methodology, architecture, WBS, risks |
| Mid-Term Evaluation | `midterm-evaluation` | prototype, validation, results, viva notes |
| Phase III — Implementation | `phase-3-implementation` | implementation manifest, security, operations |

The source implementation belongs in the normal code folders. Do not commit datasets, packet captures, models, secrets, environments, or dependencies.
